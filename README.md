# AIRVPN

Next-generation high-speed VPN client application built with React, Vite, Tailwind CSS, and Express.

## Features
- **Instant Quantum Connect**: Ultra-fast one-tap connection with dynamic live ping telemetry.
- **Interactive Global Edge Map**: Visual world map with real-time server nodes and latency radar.
- **Real-Time Bandwidth Waveform**: Live oscilloscope telemetry tracking upload/download throughput.
- **Built-in Speed Test**: Ping, jitter, packet loss, and download/upload throughput diagnostics.
- **Kill Switch & Threat Shield**: Automatic DNS leak protection, ad blocking, and malicious tracker prevention.
- **Split Tunneling**: Granular per-app and per-domain routing bypass rules.
- **Encrypted DNS**: Multi-provider DNS-over-HTTPS (Automatic, Cloudflare, Google, Quad9) and custom resolver support.
- **Proxy Chaining & Proxy-Only Mode**: Route through upstream SOCKS5 or HTTP proxies, or run as a standalone local proxy.
- **One-Click Config Export**: Download WireGuard `.conf`, PAC script, or curl SOCKS5 commands.
